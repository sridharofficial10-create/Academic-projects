# Low-Cost Farm Produce Storage Monitoring System

## About the Project

This project is a simple and low-cost system designed to monitor the conditions inside a farm produce storage area.

Farmers often store vegetables, fruits, grains, and other agricultural products for a period of time after harvesting. Changes in temperature and humidity inside the storage area can affect the quality of the produce. This project focuses on monitoring these conditions so that storage conditions can be observed and managed better.

## Objective

The main objective of this project is to develop an affordable monitoring system that can continuously observe the storage environment and provide useful information about the conditions inside it.

## How It Works

The system uses sensors to measure important environmental conditions such as temperature and humidity.

The sensor readings are collected by a microcontroller and can be monitored to understand how the storage environment changes over time.

The collected readings can also be recorded and compared during different testing conditions.

### Basic Working

**Sensors → Microcontroller → Data Monitoring → Storage Condition Analysis**
